1. Introduction & Objectives
SauceDemo app is an e-commerce application where you can buy clothes and lifestyle products.
The application is made by Swag Lbs and hosted on Url : https://www.saucedemo.com/
This document states the different types of testing like e2e, smoke and regression which will be carried on the application. The test approach that will be used and the coverage that the team is going to for e2e testing.
Objectives: 
This suite aims to achieve 90% automation coverage which will include all the critical path from login to product checkout and logout and also negative scenarios like hitting page URL directly.
The suite is designed so that any engineer can understand the testing decisions made and how to scale the suite themselves by reading through the document.
This project is a personal portfolio piece built to demonstrate professional QA automation practices


2. Scope (In Scope / Out of Scope)
In Scope - Positive , negative test for each pages and features.
E2E test for critical flows covering each page
Out of scope - No API testing covered as this is purely UI designed
